# MQR

### Learning pushing and grasping policy using Offline Reinforcement Learning

## Installation

This code has been tested with python 3.9, pytorch 1.12.0, CUDA 11.3, cuDNN 8.2.1 on Ubuntu 20.04.

Create the conda env and install necessary python libraries.
```
conda env create -f vpg.yaml
```

## Inference
```shell
python train.py
```
